# Anthony Jaimez — Portfolio

Personal site for Anthony Jaimez, IT Support Specialist building software with AI.

The page opens with a help desk ticket that resolves on load — a nod to five years of enterprise support work — followed by projects, experience and skills.

## Stack

- [Next.js](https://nextjs.org) (App Router), React, TypeScript
- CSS Modules with light and dark themes driven by `prefers-color-scheme`
- Self-hosted Schibsted Grotesk via Fontsource
- Deployed on Vercel

## Editing content

All copy lives in [`src/content.ts`](src/content.ts): profile, projects, experience, education and skills. Change it there and the page updates.

## Running locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
